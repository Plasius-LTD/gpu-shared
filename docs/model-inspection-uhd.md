# Model inspection at UHD resolution

Parent Feature: Plasius-LTD/plasius-ltd-site#1170; Story #2303; shared Task #143; viewer Task #58. Inherited flag `gpu-demo.scene-fidelity.enabled`; explicit localhost review override only.

Add exact 1920×1080, 2560×1440 and 3840×2160 render targets alongside existing viewport-shaped quick sizes. UHD is actual traced pixels, independent of browser DPR or CSS size. Preserve aspect using contained canvas presentation. Shared quality admission accepts dimensions up to 3840 with a total cap of 3840×2160 pixels. Reject oversized inputs before resource allocation; do not silently downscale. Existing renderer adapter/storage admission remains authoritative. At UHD, progressive float32 history is 132,710,400 bytes plus a 16-byte count uniform, below the default 128 MiB binding limit; other textures and scene resources are additional.

Preserve single-flight scheduling, camera state, visible GPU errors, cancellation and cleanup. Expose a one-sample option for expensive full-resolution inspection. Test native dimensions, viewport independence of fixed presets, aspect-preserving display, pixel-budget admission and reset/cleanup. Validate a real 4K frame and changed-source LCOV before delivery.

Adaptive per-pixel integration depends on renderer Task #173 (canonical configuration/statistics API), shared Task #118 (forwarding contract) and the experimental runtime in renderer PR #216. The current native adaptive runner is a diagnostic harness that intercepts GPU resource creation; the public compute renderer has no adaptive option. Do not import this test harness into the showcase, label uniform batches as per-pixel adaptive sampling, or enable the default-off `renderer.sampling.adaptivePerPixel.enabled` flag. Qualification and API integration remain open in the adaptive workstream; this resolution change is independent. Existing fixed SPP progressive rendering remains the available mode.
